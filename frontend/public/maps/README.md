# Map sources and attribution

`wb-light.json` is an adaptation of OpenFreeMap Positron, downloaded from
https://tiles.openfreemap.org/styles/positron on 2026-11-11.
Changes: neutral/violet palette, Russian labels, removal of road shields.
3D buildings and route overlays are added by the application.

OpenFreeMap styles: https://github.com/hyperknot/openfreemap-styles
