# Прогноз отгрузок

На ветке `web` доступен локальный дашборд для просмотра сохранённых прогнозов модели по направлениям. Интерфейс показывает значения на одну выбранную временную точку: каждое значение — прогноз числа отгруженных товаров за предыдущий час. Соседние периоды перекрываются и не складываются между собой.

## Запуск через Docker

В `data/raw/` должны находиться:

- `test_solo_track.parquet` — сопоставление `id`, направления и времени;
- `catboost_88.csv` — предоставленный результат с колонками `id,y_pred`.

Оба файла остаются локальными и не входят в Git. Оригинальный CSV можно положить сюда из папки Downloads без изменения его содержимого.

```bash
docker compose up --build
```

Откройте <http://localhost:8080>. При первом запуске исходный CSV импортируется автоматически. Результаты последующих загрузок сохраняются в `data/processed/web/` и остаются доступны после остановки контейнеров. Можно загрузить другой CSV с тем же набором уникальных `id`; файл проверяется до сохранения, а кнопка скачивания возвращает оригинальные байты.

## Локальная разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cd frontend && npm ci && cd ..
cd backend && ../.venv/bin/uvicorn app.main:app --reload
```

В другом терминале:

```bash
cd frontend
npm run dev
```

Откройте адрес Vite из терминала (обычно <http://localhost:5173>). Сервер разработки проксирует `/api` на порт 8000. Если ваши данные расположены в другой папке, задайте `FORECAST_DATA_DIR` как путь к каталогу, содержащему `raw/` и `processed/`.

Запуск модели из интерфейса пока не подключён: текущий файл содержит готовый исторический прогноз на 1 ноября 2025 года. Для запуска инференса понадобятся обученные артефакты и совместимая точка входа; интерфейс не имитирует выполнение модели. Исходный обучающий ноутбук — [main.ipynb](main.ipynb).

## Карта маршрутов

Вкладка «Маршруты» показывает отдельный демонстрационный путь для каждого направления, объёмные здания и модель фуры. Есть поиск по номеру и городу, пауза, перемотка, повтор, общий вид, камера у фуры и переключатель 2D/3D. Перейти на карту можно и из деталей направления в таблице.

География намеренно демонстрационная: исходный CSV не содержит GPS, адресов складов или состояния рейса. Направления распределяются по десяти российским городам; каждый получает отдельный участок сохранённой дорожной линии. Перемещение фуры — управляемая анимация, не телеметрия. Значения отгрузок и график остаются реальными результатами CSV, дата и временной срез сохраняются.

Карта использует MapLibre GL JS, Three.js и [OpenFreeMap](https://openfreemap.org/). Ключ API и регистрация не нужны. Для загрузки карты нужен интернет и браузер с WebGL 2; карта подгружается только при открытии вкладки. При недоступности карты прогнозы остаются доступны, на карте появляется кнопка повтора.

Геометрия дорог из [OSRM](https://project-osrm.org/) / [OpenStreetMap](https://www.openstreetmap.org/copyright) сохранена в `frontend/src/routes/cities.json`. В пользовательском браузере запросы к маршрутизатору не выполняются. Скрипт `python3 scripts/fetch-demo-routes.py` обновляет десять исходных дорожных линий без передачи данных модели. Эти демонстрационные автомобильные пути не учитывают ограничения для грузовиков.

Чтобы подключить настоящую логистику, замените каталог в `frontend/src/routes/catalog.ts` на координаты и геометрию по `route_id`, а воспроизведение — на GPS-позиции. Это не требует замены интерфейса или 3D-модели. Источники и лицензии стиля карты: `frontend/public/maps/`.

После обновления существующего Docker-развёртывания пересоберите приложение:

```bash
docker compose up --build
```

Дополнительные проверки геометрии и сопоставления всех 1 000 направлений: `npm --prefix frontend test`.
