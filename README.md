# Прогноз временных рядов

Прогноз на 8 получасовых горизонтов для 1000 маршрутов.

Используются CatBoost MultiRMSE и дополнительный ансамбль из двух CatBoost, MLP, LightGBM и XGBoost.

Замечание: прошлые и актуальные эксперименты/гипотезы находятся в приватном репозитории.

**Веса основного CatBoost / ансамбля:**
- Горизонт 1 — 50/50
- Горизонт 2 — 40/60
- Горизонты 3–8 — 25/75

Внутри дополнительного ансамбля веса моделей: 30/30/20/10/10.

## Запуск

Поместить исходные Parquet-файлы в `data/raw/`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Открыть `main.ipynb`, выбрать окружение `.venv` и выполнить все ячейки.

Результат: `data/processed/submission.csv`.
