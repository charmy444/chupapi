# Прогноз отгрузок

На ветке `web` доступен локальный дашборд для просмотра сохранённых прогнозов модели по направлениям. Интерфейс показывает значения на одну выбранную временную точку: каждое значение — прогноз числа отгруженных товаров за предыдущий час. Соседние периоды перекрываются и не складываются между собой.

## Запуск через Docker

В `data/raw/` должны находиться:

- `test_solo_track.parquet` — сопоставление `id`, направления и времени;
- `catboost_88.csv` — предоставленный результат с колонками `id,y_pred`.

Оба файла остаются локальными и не входят в Git. Оригинальный CSV можно положить сюда из папки Downloads без изменения его содержимого.

```bash
docker compose up --build
```

Откройте <http://localhost:8080>. При первом запуске исходный CSV импортируется автоматически. Результаты последующих загрузок сохраняются в `data/processed/web/` и остаются доступны после остановки контейнеров. Можно загрузить другой CSV с тем же набором уникальных `id`; файл проверяется до сохранения, а кнопка скачивания возвращает оригинальные байты.

## Локальная разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
cd frontend && npm ci && cd ..
cd backend && ../.venv/bin/uvicorn app.main:app --reload
```

В другом терминале:

```bash
cd frontend
npm run dev
```

Откройте адрес Vite из терминала (обычно <http://localhost:5173>). Сервер разработки проксирует `/api` на порт 8000. Если ваши данные расположены в другой папке, задайте `FORECAST_DATA_DIR` как путь к каталогу, содержащему `raw/` и `processed/`.

Запуск модели из интерфейса пока не подключён: текущий файл содержит готовый исторический прогноз на 1 ноября 2025 года. Для запуска инференса понадобятся обученные артефакты и совместимая точка входа; интерфейс не имитирует выполнение модели. Исходный обучающий ноутбук — [main.ipynb](main.ipynb).
